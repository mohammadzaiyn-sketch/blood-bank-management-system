# Blood Bank Management System

## About the Project

Blood Bank Management System is a college project designed to manage blood donor information, blood inventory, and blood requests through a centralized application.

##  Objective

- Manage blood donor records
- Maintain blood inventory information
- Handle blood requests
- Organize blood-banks related data efficiently

##  Technologies

- Web Application
- MongoDB / MongoDB Atlas
- Database Management
- Cloud Deployment
